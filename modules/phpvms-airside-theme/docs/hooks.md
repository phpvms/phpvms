# airside hooks

Every hook airside exposes for styling. See [customizing.md](customizing.md) for
how hooks work and how to override them.

Each entry lists the hook class, the view it is in, its parts, its state
attributes and its CSS variables. Add an entry in the same change that adds a
hook.
